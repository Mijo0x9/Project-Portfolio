Projects, more and more.

HEXNET – DeltaHex (semi-public)
A free-to-use network for device encryption,
with support for Bluetooth, Wi-Fi, LoRa and more.
Part of the wider DeltaHex ecosystem: a modular hub ("The Shard") with LoRa/Meshtastic,
attachable sensor modules, and time-based authentication between devices.

D.E.L.T.A – AI (private)
An AI assistant with a unique structure for speed and ease of use,
with multiple ways to communicate with the user and a sandboxed shell.
Runs on a Telegram interface with two-tier memory, a model fallback chain
and the ability to write its own tools.
Also integrated into Home Assistant as a custom conversation agent.
The D.E.L.T.A project is private due to the risk of it being used outside a sandbox, container or virtual machine.

D.E.L.T.A Watch OS
Custom firmware for an ESP32-S3 AMOLED touch watch (Waveshare).
Dual-core build with a radial app drawer, watchface engine and apps like Flashlight, Timer, 2048 and Settings.
Includes a PC Monitor applet that streams my PC screen to the watch over TCP
and sends touch back as mouse input, plus a voice recorder that uploads to my server.

Smart Home Controller
A wall-mounted controller on a 360×360 round touch display (ESP32-S3).
Five-page UI with an HSV color wheel for lights, HVAC toggle, TV + amp control with a rotary volume gesture,
all talking to Home Assistant through webhooks.

HexHub
A Raspberry Pi 4 hub daemon that detects USB devices instantly and hands them to my main PC over USB/IP,
with network audio in/out and a projector mode for connected displays.

Homelab (Proxmox)
A Proxmox server running a GPU-passthrough CachyOS desktop streamed with Sunshine/Moonlight,
Home Assistant, OpenMediaVault, Jellyfin, OctoPrint for 3D printing,
and a Python container that hosts my own apps with a launcher, watchdog and backups.

Jellyfin Custom Theme
A custom CSS theme for my Jellyfin server with a YouTube × Netflix look,
a movie-style layout and a responsive grid for separate PC and phone layouts.

Call Log Analyzer
A Python desktop tool (tkinter + matplotlib) with live Dutch/French/German/English switching.
Has its own licensing system using Ed25519 signing and machine binding,
backed by a two-port Flask architecture.

DELTA File Manager
A Flask web app with a single-page frontend and a CodeMirror editor,
drag-and-drop uploads, batch downloads as ZIP, recursive search and a drive browser.

Last Stand Password Manager
A single-file Flask password manager with AES-256-GCM vault encryption,
TOTP two-factor login, magic-link login, a kill switch and USB monitoring.

DELTA Miner
A Lua mining program for Minecraft (CC:Tweaked turtles) with XYZ and area modes,
fuel and inventory management, save/resume and a retro amber terminal UI.
Also built a Command Computer program that syncs real-time weather and time into the game.

Call Screening Trap
A custom voicemail setup that keeps robocallers talking to nothing,
while still recording callers so I can listen back and spot scams.

Stream Branding
Animated DELTA brand visuals and logo work made in DaVinci Resolve / Fusion.

Electronics Builds
A Class D amplifier (TPA3116/TPA3255) built for home theater speakers,
and a Raspberry Pi 4 Moonlight thin client.
